\section{Finite specifications and exact verification}\label{app:certificates}
The finite constructions can be reconstructed without the final graph matching. We give the characteristic-three difference set and the formulas for the small Paley matrices, followed by a polynomial certificate for the restricted comparison with Mghirbi--Douglas's unchanged kernel. The last item is a mathematical obstruction, not merely a test of the implementation. The supplementary files \texttt{SOURCES.md} and \texttt{DEPENDENCIES.md} identify the source versions and the mathematical inputs used in each theorem. The verification code uses Python integers and rational arithmetic for certificates, and fixed-width integer arrays only for the explicitly bounded small incidence and Hadamard calculations.

\subsection{Paley matrices used in Table~\ref{tab:small-primes}}

These formulas specify the actual auxiliary matrices used in the small examples. Normalizing them recovers both design Gram identities of Lemma~\ref{lem:hadamard}, so the table depends on finite matrix arithmetic rather than an external list of known orders.
Let $\chi$ be the quadratic character of a finite field $\F_s$, with $\chi(0)=0$, and put $C_{ij}=\chi(i-j)$. The standard character identity gives $CC^{\mathsf T}=sI-J$ and $C\one=0$. If $s\equiv3\pmod4$, the matrix
\[
 H=\begin{pmatrix}1&\one^{\mathsf T}\\-\one&C+I\end{pmatrix}
\]
has $HH^{\mathsf T}=(s+1)I$. If $s\equiv1\pmod4$, put
\[
 A_s=\begin{pmatrix}0&\one^{\mathsf T}\\\one&C\end{pmatrix},
 \qquad
 H=\begin{pmatrix}A_s+I&A_s-I\\A_s-I&-A_s-I\end{pmatrix}.
\]
Here $A_s^2=sI$, so $HH^{\mathsf T}=2(s+1)I$. These are Paley's type~I and type~II constructions \cite{Pal33}. Row and column sign changes normalize the matrices without changing their Hadamard identities.

The implementation constructs prime fields directly and uses $\F_{25}=\F_5[u]/(u^2-2)$ for the order-$52$ example. The polynomial is irreducible because $2$ is a nonsquare modulo five. Every entry and both design Gram identities are checked after normalization. The six resulting matrices are stored in \texttt{data/hadamard\_matrices.json}. No external matrix database or third-party matrix-generation code is used.

\subsection{A spectral obstruction for the unchanged MD model}
The following comparison concerns only the specific auxiliary blocks, frequencies, and conditional kernel of \cite[Section~7]{MD26}. It does not prohibit smaller parameters after a change of finite design.
\begin{proposition}\label{prop:md-obstruction}
Keep the MD direct-finiteness auxiliary system, with $e=p^2+p+1$ and auxiliary reduced-turn weight $(p-1)/p$, but replace its plane order by $q=p^4$. Its squared-turn kernel has spectral radius greater than one for every odd prime $p$. In fact the same quotient obstruction holds for every real $p\ge3$.
\end{proposition}
\begin{proof}
Set $v=q^2+q+1$, $a=(q+1)^{-2}$, $b=(q+1)^2/v^2$, and $g=(p-1)/p$. The three-class quotient is
\[
 Q=\begin{pmatrix}
 eb&(e-1)g^2&(v-e)b\\
 (e-1)a&eb&(v-e)a\\
 ea&eb&(v-e-1)a
 \end{pmatrix}.
\]
Direct rational expansion at $q=p^4$ gives
\begin{equation}\label{eq:md-determinant}
 \det(I-Q)=\frac{-P(p)}{(p^4+1)^3(p^2-p+1)^4(p^2+p+1)^2(p^4-p^2+1)^4},
\end{equation}
where the coefficients of $P$, in descending order from degree $31$ to degree zero, are
\[
\begin{split}
 (&1,1,0,-1,1,12,-4,-14,11,31,-21,-31,26,43,-37,-46,\\
  &40,38,-45,-36,37,18,-31,-17,22,4,-15,-1,7,-2,-2,1).
\end{split}
\]
All $32$ coefficients of $P(u+3)$ are positive; its constant is $833193976801090$. This is an integer certificate: if $c_k$ denotes the coefficient of $p^k$ in the displayed list, each coefficient is the explicitly checkable sum
\[
 [u^j]P(u+3)=\sum_{k=j}^{31}c_k\binom{k}{j}3^{k-j}>0
 \qquad(0\le j\le31).
\]
The accompanying program expands the determinant independently, compares every coefficient of $P$, and verifies these $32$ positive sums. Thus \eqref{eq:md-determinant} is negative for $p\ge3$. The real polynomial $\det(tI-Q)$ is positive for sufficiently large positive $t$, so it has a root greater than one. That root is an eigenvalue of the full equitable kernel. Its spectral radius is therefore greater than one.
\end{proof}

The observation following \cite[Lemma~7.8]{MD26} shows that their displayed sufficient inequality fails at $q=p^4$. Proposition~\ref{prop:md-obstruction} instead verifies failure of contraction for the unchanged kernel itself. Neither statement claims optimality over other auxiliary designs or other frequency choices.

\subsection{Reproduction and scope}
From the supplementary package root run
\begin{verbatim}
python -m pip install -r requirements.txt
python verify/verify.py --output checks/results.json
\end{verbatim}
Assertions must remain enabled. The program reconstructs the finite data, compares the two stored certificate files, and writes a new results file; it does not modify the input certificates. It also checks the rational certificates of Table~\ref{tab:small-primes}, the polynomial in \eqref{eq:md-determinant}, the error constants in \eqref{eq:char3-errors}, the degree-based girth parameters, and sample boundary values for both asymptotic parameter deductions. The universal inequalities in Section~\ref{sec:quantitative} are proved there, not inferred from these samples.

The large Hadamard matrices supplied by the external existence theorems are not constructed by these programs, and the complementary-sequence computations underlying those sources are not repeated. The programs check finite arithmetic and specified finite arrays; they neither find the terminal graph matching nor decide equality in its group. The probabilistic and topological conclusions are supplied by their separately stated proofs and cited inputs.
